# Power BI Loan Portfolio Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze loan portfolio data and provide meaningful business insights.

## Objectives

* Analyze total loan amount and loan performance
* Understand customer and loan characteristics
* Identify key trends and patterns
* Create interactive KPIs and visualizations
* Present business insights through an easy-to-use dashboard

## Tools Used

* Power BI
* Power Query
* Excel / CSV

## Key Dashboard Insights

The dashboard includes:

* Total Loan Amount
* Total Customers
* Loan Count
* Interest Rate Analysis
* Loan Status
* Customer Segmentation
* Loan Trends
* Interactive Filters and Slicers

## Data Preparation

The dataset was cleaned and transformed using Power Query before creating the dashboard. This included checking data types, handling missing values, and preparing the data for analysis.

## Dashboard

The Power BI dashboard provides interactive visualizations and KPIs that allow users to analyze the loan portfolio from different perspectives.

## Business Value

The dashboard helps management understand loan portfolio performance, customer trends, and key lending metrics to support data-driven decision-making.
